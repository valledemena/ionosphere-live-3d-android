# Ionosphere Live 3D - Android

Companion mobile app for the **Ionosphere Live 3D** project (desktop in `ionosphere-live-3d`, web in `ionosphere-live-3d-web`).

This repository is intentionally starting as a coordination-first mobile project:
- GLM authors plan/reviews/architecture there.
- David validates on Android devices, builds/publishes.
- Beam acts as tooling/wharehouse on the PC (clones, tests, GitHub flows).
- Desktop / Web repos are read-only starting points; the Android app re-implements the experience with mobile constraints.
